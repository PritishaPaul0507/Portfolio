# Pritisha Paul | Portfolio

Single-file portfolio (HTML/CSS/JS, no build step) with a cursor-tracking avatar,
and slide-out Resume and Contact drawers.

## Run locally
Open `index.html`, or: `python3 -m http.server 8000`

## Custom avatar
See `assets/avatar/README.md`.

## Deploy (GitHub Pages)
Repo Settings > Pages > Deploy from branch > `main` / root.
