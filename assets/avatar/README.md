# Avatar poses

Add 9 PNGs here (same size, same framing, transparent or matching background). Names = where the avatar looks:

| ul | u | ur |
|----|---|----|
| l  | c | r  |
| dl | d | dr |

`c.png` is required (looking at the viewer). Missing poses fall back to `c.png`.
If `c.png` is absent the site shows the built-in drawn avatar.

Tip: generate ONE base character in an image tool, then ask for the same character
with eyes/head turned in each direction, keeping style and outfit identical.
